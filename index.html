《球来》隐私政策

更新日期：2026年11月7日 · 生效日期：2026年11月7日
运营主体：娜姐工作室 · 联系邮箱：504064868@qq.com

娜姐工作室重视您的隐私。本政策说明《球来》（Qiulai）当前核心游戏版本的数据处理方式，以及如何联系我们。

一、游戏处理哪些数据

当前游戏无需注册游戏账号。游戏在您的设备或运行容器的本地存储中保存关卡进度、道具数量、已完成的引导、音乐音效与振动设置，以及用于调整关卡难度的游戏记录。这些记录包括进入关卡、失败、胜利、重开、连续通关情况及奖励广告流程次数，用于恢复进度和调整游戏体验。

当前核心游戏代码未接入开发者自建业务服务器、第三方统计或真实广告 SDK，不会主动将上述本地存档上传至娜姐工作室服务器，也不主动读取您的通讯录、精确位置、照片、麦克风或摄像头。

二、数据使用与保存

上述本地数据仅用于提供、保存和调整游戏功能。在您清除游戏或宿主应用的相应数据前，本地存档可能持续保留。卸载、清理缓存或更换设备可能造成进度丢失；当前版本不提供开发者云端存档同步。

三、运行平台、广告与第三方服务

游戏可能运行于 OpenPaaS 或其他宿主平台。宿主平台自身提供的账号、网络、安全或广告服务可能独立处理数据，其具体范围以该平台的隐私政策和实际授权提示为准。本政策对核心游戏代码的说明不代表宿主平台不处理任何数据。

当前核心版本的奖励广告接口使用本地调试结果，未接入真实广告 SDK。如后续发布版本接入广告、统计或其他第三方 SDK，我们会先更新本政策，列明服务提供者、处理目的、数据种类及政策链接，并按实际适用要求提供告知及授权入口。

四、隐私政策网页

本网页由 GitHub Pages 托管，不添加分析脚本、广告追踪器或非必要 Cookie。GitHub 作为托管服务商可能处理 IP 地址等访问日志，详见 GitHub 隐私声明。URL 的 language 参数仅用于选择显示语言，不用于识别用户。

五、联系我们时提供的信息

当您发送邮件咨询、反馈或提出隐私请求时，我们会收到您的发件邮箱及主动提供的内容，仅用于回复、处理问题及必要的后续沟通。请勿发送与问题无关的敏感信息。相关内容在处理及必要留存目的完成后删除，法律要求保留的除外。

六、您的选择与请求

您可以在游戏中调整声音等设置，也可以通过设备或宿主平台提供的数据管理功能清除游戏本地数据。清除数据会删除本地进度及道具记录。对于我们实际持有的邮件沟通信息，您可以通过下方邮箱请求查阅、更正或删除；我们会核实请求并回复处理结果。

七、未成年人

未成年人应在监护人指导下使用游戏，并遵守宿主平台的年龄、使用时间及授权要求。监护人如发现未成年人向我们提供了不应提供的个人信息，可以联系我们申请核查和删除。

八、安全与政策更新

我们会采取与实际数据处理相适应的措施保护信息。如功能或数据处理方式发生变化，我们会更新本页及更新日期，并根据实际适用要求提供进一步通知或取得同意。

Qiulai Privacy Policy

Last updated: November 7, 2026 · Effective: November 7, 2026
Operator: 娜姐工作室 (Najie Studio) · Email: 504064868@qq.com

娜姐工作室 (Najie Studio) values your privacy. This policy explains how the current core version of Qiulai handles data and how to contact us.

1. Data handled by the game

The current game does not require a game account. It stores level progress, item inventory, completed tutorials, music, sound and vibration preferences, and gameplay records used to adjust difficulty in the local storage of your device or game container. These records include level entries, losses, wins, restarts, win streaks and rewarded-ad flow counts. They support progress recovery and gameplay adjustments.

The current core game code does not integrate a developer-operated business server, third-party analytics or a live advertising SDK. It does not actively upload these local saves to Najie Studio servers or actively access your contacts, precise location, photos, microphone or camera.

2. Use and retention

Local data is used to provide, save and adjust game functions. It may remain until you clear the relevant game or host application data. Uninstalling, clearing storage or changing devices may erase progress. The current version does not provide developer-operated cloud save synchronization.

3. Host platforms, ads and third parties

The game may run within OpenPaaS or another host platform. Account, network, security or advertising services supplied by the host may process data independently under that platform's privacy policy and permission notices. Statements about the core game code do not imply that the host processes no data.

The current core version uses local debug results for its rewarded-ad interface and has no live ad SDK integration. Before a future release adds advertising, analytics or other third-party SDKs, we will update this policy with providers, purposes, data categories and policy links, and provide notices and authorization mechanisms as applicable.

4. This policy website

This website is hosted on GitHub Pages and adds no analytics scripts, advertising trackers or nonessential cookies. GitHub, as the hosting provider, may process access logs such as IP addresses. See the GitHub Privacy Statement. The language URL parameter only selects the displayed language and is not used to identify visitors.

5. Information you send us

When you email a question, feedback or privacy request, we receive your sender address and the content you choose to provide. We use it to reply, address the issue and conduct necessary follow-up. Please avoid unrelated sensitive information. We delete this information when handling and necessary retention purposes are complete, except where retention is legally required.

6. Your choices and requests

You can change sound preferences in the game and clear local game data using the controls supplied by your device or host platform. Clearing data deletes local progress and inventory. You can email us to request access, correction or deletion of email correspondence we actually hold. We will verify your request and respond with the outcome.

7. Minors

Minors should use the game with guardian guidance and follow the host platform's age, usage-time and authorization requirements. Guardians who believe a minor has sent us personal information that should not have been provided may contact us to request investigation and deletion.

8. Security and updates

We will use safeguards appropriate to our actual data processing. If features or data practices change, we will update this page and its revision date, and provide further notice or seek consent as applicable.
